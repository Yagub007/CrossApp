## 2. Метод ParseLine — 2–3 патерни
```bash
grep -n -A15 "ParseOutcome ParseLine" src/Core/Import/ProductCsvImporter.cs
```
**Що сказати (обери 3):**
- `{ Length: < 4 }` — патерн властивості + порівняння: замало колонок;
- `[_, "", _, _]` — патерн списку з константою: порожня назва;
- `[_, _, var price, _] when !TryPrice(...)` — охоронна умова when: некоректна ціна;
- `[var id, var name, var price, var cat]` — список зі зв'язуванням: успіх.

## Відповіді на 2–3 питання (готові)

**П: Чим record кращий за class для рядка файлу?**
Рядок — це просто дані: порівнюються за значенням, не змінюються. record дає це «безкоштовно»; class потрібен для об'єктів із поведінкою (з тижня 4).

**П: Навіщо ImportResult, а не виняток на першій помилці?**
Щоб один зіпсований рядок не зупиняв імпорт 500 інших. Повертаємо і дані, і список помилок — виклик сам вирішує, що робити.

**П: Навіщо InvariantCulture при розборі ціни?**
Щоб `"189.50"` читалось однаково на будь-якій локалі. На українській локалі (кома-роздільник) без цього крапка зламала б число.
