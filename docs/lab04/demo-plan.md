## 1. Показати сутність: приватне поле, властивість без set, приватний конструктор
```bash
cat src/Core/Domain/Order.cs
```
**Що сказати:** «Стан прихований: колекція `_lines` приватна, `Id`/`CustomerId` — тільки читання, `Status` — `private set`. Конструктор приватний, тому створити об'єкт можна лише через фабрику `Create`, де всі перевірки.»

## 2. Пояснити один інваріант і запустити сценарій, де він спрацьовує
```bash
dotnet run --project src/Cli
```
**Показати рядок** зі сценарію 2, напр.:
`додати рядок у підтверджене: InvalidOperationException — Замовлення O-001 у статусі Confirmed: рядки додавати не можна`
**Що сказати:** «Інваріант: до підтвердженого замовлення не можна додавати рядки. Перевірка в `AddLine` кидає `InvalidOperationException` — операція неможлива в поточному стані.»

## 3. Спробувати присвоїти властивість напряму — помилка компіляції
У редакторі (або терміналом) додати в Program.cs рядок:
```csharp
order.Status = OrderStatus.Draft;   // ❌ не компілюється — set приватний
```
```bash
dotnet build 2>&1 | grep -i error
```
**Що сказати:** «Пряме присвоєння ззовні не компілюється — `Status` має `private set`, `_lines` приватне. Стан можна змінити лише методом класу.»
> Після демо прибрати цей рядок.

## 4. Показати, що після всіх відмов стан не змінився
У виводі — останній рядок сценарію 2:
`Стан order не змінився: статус Confirmed, рядків 2, сума 507,70`
**Що сказати:** «Перевірки виконуються ДО зміни полів, тому жодна невдала спроба не зіпсувала об'єкт — сума й статус ті самі.»

## Відповіді на 2–3 питання (готові)
**П: Що таке інваріант?** Умова, істинна протягом усього життя об'єкта (напр. «кількість у рядку > 0»). Перевіряється у фабриці/методах, порушення → виняток.
**П: Чому конструктор приватний?** Щоб об'єкт створювався лише через `Create`, де всі перевірки — інакше можна було б зробити некоректний об'єкт напряму.
**П: Коли ArgumentException, а коли InvalidOperationException?** Argument* — поганий вхідний аргумент (порожній Id, від'ємна ціна). InvalidOperation* — аргумент нормальний, але стан не дозволяє (додати рядок у підтверджене).
